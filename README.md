# Wolent CMS — Marketing Site

Professional landing page and documentation site for [Wolent CMS](https://wolent.com), an open-source headless CMS.

## Tech Stack

- Next.js 15 (App Router)
- Tailwind CSS v4
- TypeScript
- Static Site Generation (SSG)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Pages

- `/` — Landing page
- `/docs` — Documentation with sidebar navigation
